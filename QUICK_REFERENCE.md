## 💡 How It Works

### User Journey
```
1. User visits http://localhost:5000
   ↓
2. Lands on marketing page
   ↓
3. Clicks "Get Started" or "Sign In"
   ↓
4. Creates account or logs in
   ↓
5. Redirected to dashboard
   ↓
6. Views real-time events (150+)
   ↓
7. Reads feedback entries (16)
   ↓
8. Checks AI recommendations
   ↓
9. Creates/manages alerts
   ↓
10. Copies API key for integration
```

### Data Flow
```
External App
    ↓
[NPM SDK or REST API]
    ↓
PM-AI Server
    ↓
Database (PostgreSQL)
    ↓
Dashboard Display
    ↓
User sees insights
```

## 🔌 Integration Methods

### Method 1: NPM SDK (Recommended)
```javascript
import { createAPMClient } from "@saas-apm/apm-sdk";

const apm = createAPMClient({
  apiKey: "pk_live_xxx",
  endpoint: "http://localhost:5000"
});

apm.trackEvent("feature_used", { feature: "export" });
```

### Method 2: REST API
```bash
curl -X POST http://localhost:5000/api/events \
  -H "Authorization: Bearer pk_live_xxx" \
  -d '{"type":"page_view","payload":{"page":"/"}}' \
```

### Method 3: Web UI
- Users submit feedback directly
- Events captured automatically
- No code needed
